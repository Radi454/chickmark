# Implementation Plan: Phase 3 — All Audit Entry Screens

**Branch**: `004-audit-entry-screens` | **Date**: 2026-04-18 | **Spec**: [spec.md](spec.md)

## Summary

Build the complete 3-step new audit entry flow and all 5 data entry screens (Chick Quality, Hatch Analysis, Setter Optimizing, Hatcher Optimizing, Egg Storage & Handling). Data entry is tab-based where applicable, with per-tab save that turns the tab green. All calculations update in real time. SQLite is the source of truth; Supabase syncs in the background. Two calculation bugs in `CalculationUtils` must be fixed first (pasgarScore and uniformityPercent formulas are incorrect per the constitution). A DB schema migration (v1→v2) adds the `hatchNumber` column to support multiple hatches per session.

  AuditModel get activeDraft
  bool isTabSaved(int tab)          // for active hatch
  bool get isLoading

  // Actions
  void updateField(String key, dynamic value)   // updates activeDraft field

## AuditProvider → AuditRepository Flow

```
User taps Save (tab N)
  → AuditProvider.saveTab(N)
    → Serialize activeDraft to Map
    → AuditRepository.insertAudit(draft) [SQLite, ConflictAlgorithm.replace]
    → _savedTabs[activeHatchIndex].add(N)
    → notifyListeners() [tab indicator turns green]
    → fire-and-forget: SupabaseService.syncAudit(draft.toMap())
```

## Calculation Bug Fixes (BLOCKING — do first)

### Fix 1: `pasgarScore`

```dart
// WRONG (current):
static double pasgarScore(int eggs, List<int> scores) {
  return 10 - (sum * 2 / eggs);   // incorrect formula
}

// CORRECT (constitution XII):
static double pasgarScore(int sampleSize, List<int> defectCounts) {
  if (sampleSize == 0) return 0.0;
  final sum = defectCounts.fold(0, (a, b) => a + b);
  return double.parse(
    (((sampleSize * 10) - sum) / sampleSize).toStringAsFixed(1)
  );
}
```

### Fix 2: `uniformityPercent`

```dart
// WRONG (current): returns % OUTSIDE range
// CORRECT: return % INSIDE range (AVG ± 10%)
static double uniformityPercent(List<double> values, double min, double max) {
  if (values.isEmpty) return 0.0;
  final inRange = values.where((v) => v >= min && v <= max).length;
  return double.parse(((inRange / values.length) * 100).toStringAsFixed(1));
}
```

Unit tests for both fixes must be written to `test/calculation_utils_test.dart` before implementation begins.
