# Implementation Plan: Phase 2 — Customers & Flocks Screen

**Branch**: `003-customers-flocks-screen` | **Date**: 2026-04-18 | **Spec**: [spec.md](spec.md)

## Summary

Implement the Customers tab with a searchable customer list, Add Customer bottom sheet, Customer Detail screen with flock management (dropdown, Add Flock, age calculation), and a read-only Audit History section. Data is written to SQLite first; Supabase sync is fire-and-forget. All UI follows the ChickMark design system (orange gradient header, `#f0f2f5` background, 14px card radius).

## Technical Context

**Language/Version**: Dart 3 / Flutter SDK ^3.10.7
**Primary Dependencies**: provider ^6.1.2, sqflite ^2.3.3+1, supabase_flutter, uuid (for ID generation)
**Storage**: SQLite via `sqflite` (source of truth) + Supabase background sync
**Testing**: `flutter test` — unit tests for `HatchDateUtils` (already exist); no new widget tests required per constitution
**Target Platform**: macOS (development), iOS (primary production target)
**Project Type**: Mobile app (Flutter)
**Performance Goals**: Customer list search filters visibly within 300 ms; audit history for 200 records loads under 1 s
**Constraints**: Offline-first; Supabase failures must be silent; flock age never manually entered
**Scale/Scope**: < 500 customers, < 50 flocks per customer, < 200 audits per customer

## Design Details

```

```

├── AppBar: GradientAppBar(title: customer.name, actions: [EditButton (disabled, future)])

## CustomersProvider API

```dart
class CustomersProvider extends ChangeNotifier {
  // State
  List<CustomerModel> get filteredCustomers
  Map<String, int> get flockCounts
  CustomerModel? get selectedCustomer
  List<FlockModel> get flocks
  FlockModel? get selectedFlock
  List<AuditModel> get audits   // for selected customer, newest first
  bool get isLoading

  // Actions
  Future<void> loadCustomers()
  void setSearchQuery(String query)
  Future<void> addCustomer(CustomerModel customer)
  Future<void> selectCustomer(CustomerModel customer)  // loads flocks + audits
  Future<void> addFlock(FlockModel flock)
  void selectFlock(FlockModel? flock)
}
```
