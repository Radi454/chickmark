Two ways to show each sector's scopes against the all-samples average

Option A — Tabbed: sector gets a tab bar. First tab Avg = mean of all samples (with spread + worst scope). Other tabs = each scope on its own. One view at a time, compact.

Option B — Side-by-side: one matrix. Rows = parameters, columns = Avg then every scope. The average sits next to each scope so you read deviation at a glance. Wider, no clicking.

Both shown below on two real sectors. Mock data mirrors SCOPE_DEMO in dashboard_prototype.html.

Trade-offs

Option A winsMany scopes (16 residue leaves) — tabs stay compact, won't blow up card height. Mobile-friendly. Per-scope detail gets full width.
Option B winsFew scopes (2–4 machine pairs) — direct avg-vs-scope comparison, spot the outlier instantly, no clicking. Reads like the existing scope table, just with an Avg column.
HybridOption B when ≤4 scopes, auto-switch to Option A tabs when more. Same data model feeds both.
