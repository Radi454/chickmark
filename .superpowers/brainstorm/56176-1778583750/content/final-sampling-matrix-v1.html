Sampling Data Model: Clean Matrix

Pool is the default everywhere. Compare is optional per panel. Main panel rows store context/settings; sample rows store Random or compared groups.

Global storage rule
Same pattern across all screens

Main panel table

One row per session + panel.

Stores dashboard context: session, customer, flock, date, hatchery, breed, flock age.

Stores panel settings: mode, compareLayer.

Sample table

Every panel has {panel}_samples.

Pool mode saves one row: scopeType=pool, scopeLabel=Random.

Compare mode saves one row per compared group.

Detail tables

Only when needed.

Weights use JSON on sample rows plus summary columns.

Hatch breakout trays use one physical tray per row.

Hatch Analysis special hierarchy
House is compact by default, tray rows remain physical tray rows
House grouping expands only when needed.

fresh_egg_breakout

Path: House → Tray

Compare: House or Tray

Rows: fresh_egg_breakout_samples + fresh_egg_breakout_trays

Each tray row stores direct count and percent columns.

candled_egg_breakout

Path: House → Setter → Trolley → Tray

Compare: House, Setter, Trolley, or Tray

Rows: candled_egg_breakout_samples + candled_egg_breakout_trays

Tray card top shows House + Setter ID.

residue_breakout

Path: House → Setter+Hatcher → Trolley → Tray

Compare: House, Setter+Hatcher, Trolley, or Tray

Rows: residue_breakout_samples + residue_breakout_trays

Tray card top shows House + Setter ID + Hatcher ID.
