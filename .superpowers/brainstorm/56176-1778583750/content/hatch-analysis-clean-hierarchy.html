Hatch Analysis Sampling Model

Default is always Pool. Comparison is optional and configured per sector/panel.

Global rule
Every sector starts simple
1. Pool sample
One random/default row is saved first.
2. Compare toggle
User enables comparison only when needed.
3. Layer slider
Valid layers appear for that sector only.
Hatch Analysis hierarchy
House is compact and defaults to Random
Expands only when house grouping/comparison is needed

Fresh Egg

Default: Pool

Valid compare: House, Tray

Deepest path:
House → Tray

Tray card top:
House, Label, Tray size

Candled Egg

Default: Pool

Valid compare: House, Setter, Trolley, Tray

Deepest path:
House → Setter → Trolley → Tray

Tray card top:
House, Setter ID, Position, Tray size

Residue / Hatch Day

Default: Pool

Valid compare: House, Setter+Hatcher, Trolley, Tray

Deepest path:
House → Setter+Hatcher → Trolley → Tray

Tray card top:
House, Setter ID, Hatcher ID, Position, Tray size

Storage pattern
Summary row + sample rows

Main sector table

One saved summary row for Pool, or one summary row per compared group.

Stores totals and percentages for dashboard speed.

Sample/tray table

Stores raw counts and percentages for each sample or tray.

Links to the summary row and carries the relevant identity layer.
